# Graph Studio · 图谱编辑器

一个无需构建步骤、可直接在浏览器运行的轻量图编辑器。界面为中文，示例图会展示混合图、平行边、虚线和自环。

## 运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

然后打开 `http://localhost:4173`。图数据会自动保存在当前浏览器的本地存储中。

## 功能

- 在“添加”面板输入顶点标签 `u` 创建顶点，或用画布工具点击放置；新顶点默认为白底、黑边、黑字。
- 在“添加”面板输入起点 `u`、终点 `v` 和边权 `w` 创建边。标签或顶点 ID 都可作端点；可选有向 / 无向、实线 / 虚线。重复输入可添加平行边，`u = v` 可创建自环。
- 每条边可单独设置 16 色、字符串边权和长度。普通边的长度会调整目标顶点位置；自环长度控制弧高。
- 点击顶点可直接编辑点权、标签、填充色、边框颜色与粗细。所有顶点统一大小，并根据最长标签或点权自动放大。
- 支持顶点和边列表、撤销 / 重做、JSON 导入，以及 JSON、SVG、PNG 导出。

快捷键：`V` 选择、`N` 添加顶点、`E` 连边、`Delete` 删除、`Ctrl/⌘ Z` 撤销、`Ctrl/⌘ Shift Z` 重做。
