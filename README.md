# Graph Studio · 图谱编辑器

一个无需构建步骤、可直接在浏览器运行的轻量图编辑器。界面为中文，示例图会展示混合图、平行边、虚线和自环。

## 运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

然后打开 `http://localhost:4173`。图数据会自动保存在当前浏览器的本地存储中。

## 功能

- 在画布左侧的批量输入栏逐行输入命令：1 个字符串加无点权顶点；2 个字符串加顶点（第二个为点权）；3 个字符串加无边权边（第三个为方向标记）；4 个字符串加边（第三个为边权，第四个为方向标记）。方向标记精确为 `1` 时有向，否则无向。按 `Enter` 插入换行并应用原光标所在行（若该行为空则尝试应用上一行）；多行粘贴后按 Enter 会应用截至该行的未执行命令。已应用命令会保留在输入框，删除命令行会删除对应图元素；按 `Backspace` 修改后，若本行仍是有效命令则自动重应用。重复顶点命令会复用已有顶点，避免重复创建。通过画布点击新增的顶点、边会将命令填入第一个空行；没有空行时自动追加新行。标签、点权、端点、方向和边权等命令字段的修改也会同步。输入栏默认展开，可收起。
- 边命令引用的顶点若尚不存在，会自动创建。新顶点默认为白底、黑边、黑字。边可以设置实线 / 虚线；重复边命令可添加平行边，`u = v` 可创建自环。含空格的字符串可用引号包裹。
- 每条边可单独设置 16 色、字符串边权和长度。普通边的长度会调整目标顶点位置；自环长度控制弧高。
- 点击顶点可直接编辑点权、标签、填充色、边框颜色与粗细。所有顶点统一大小，并根据最长标签或点权自动放大。
- 右侧可查看顶点和边列表；“整理成树”以所选顶点（或第一个顶点）为根生成树形布局，保留全部现有边、重边和自环。支持撤销 / 重做、JSON 导入，以及 JSON、SVG、PNG 导出。

快捷键：`V` 选择、`N` 添加顶点、`E` 连边、`Delete` 删除、`Ctrl/⌘ Z` 撤销、`Ctrl/⌘ Shift Z` 重做。
